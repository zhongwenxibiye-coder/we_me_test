---
name: 멘토의 서비스 방향 피드백
description: 사용자가 전달한 위미의 차별성과 핵심 서비스에 관한 멘토 의견
---

사용자가 전달한 멘토 의견은 위미의 강점을 전공에 관계없는 다양한 직무·직업 제안, 스스로 진로를 찾는 데 드는 시간과 위험의 감소, 직무/멘토링 서비스에 둔다.

**Why:** 사용자는 이 의견을 반영하는 새 기능을 추천해 달라고 요청했다. 이는 전달된 멘토 의견이며, 경쟁 서비스 전체에 대해 검증된 사실이나 사용자가 확정한 개발 계획은 아니다.

**How to apply:** 기능을 제안할 때 전공으로 선택지를 제한하지 않는 탐색과 현직자 확인의 연결을 우선 고려한다. 구체적인 구현이나 메뉴 개편은 별도 요청 없이 시작하지 않는다.
